소수마을: 반짝이는 농장 — 동화 농장 확장판 v2

실행
휴대폰·태블릿·컴퓨터의 최신 브라우저에서 설치 없이 링크를 열어 플레이할 수 있습니다.
휴대폰은 화면 아래 메뉴를 좌우로 밀어 모든 기능을 열고, 왼쪽 방향 패드로 이동합니다.
세로·가로 화면에 맞춰 조작 위치와 대화창 크기가 조정됩니다.
다운로드 파일을 쓰려면 압축을 풀고 decimal-farm-v2/index.html을 Chrome, Edge, Safari에서 여세요.
인터넷, 로그인, 유료 API, 별도 설치 없이 실행되는 HTML5 Canvas 게임입니다.
로컬 파일 저장이 제한되는 브라우저에서는 폴더에서 다음 명령을 실행하세요.
  python3 -m http.server 8000
그런 다음 http://localhost:8000 에 접속합니다. 종료: Ctrl+C.
온라인판과 다운로드판은 서로 다른 브라우저 저장 공간을 사용합니다.

처음 플레이
이야기를 닫고 하단 지도 → 씨앗밭을 선택하면 콩이에게 걸어갑니다.
함께 시작하기를 눌러 새로 생성된 문제의 답을 입력하세요.
주요 5문제를 마치면 다음 공간이 열립니다. 5구역 주요 25문제,
기본적으로 숫자가 바뀌는 자동 문제와 돌봄·물주기·증축·사건용 생활 수학을 제공합니다.
힌트 없이 같은 영역 3문제를 연속 맞히면 한 단계 올라갑니다. 4단계까지 있습니다.
두 번 틀리거나 도움을 받은 연습이 이어지면 다음 문제가 쉬워집니다. 재산 감점은 없습니다.
일반 연습 4문제마다 소수 관계 문제가 나오고, 주민의 별도 버튼으로 계속 연습할 수도 있습니다.
소수 관계: 크기 비교, 같은 값 찾기, 덧셈 빈칸, 0.1·0.01이 모인 수.
설정에서 자동 문제를 끄면 기존 40문제 은행을 사용할 수 있습니다.
정답은 농장 성장, 별씨앗, 경험치, 목재와 연결됩니다.
3.5와 3.50은 같은 정답입니다. 오답은 재산을 줄이지 않습니다.

조작과 생활
WASD/방향키 이동, E 대화, 바닥 클릭/터치 경로 이동.
하단 지도에서 행선지 선택, 우측 +/− 확대축소, 집 아이콘 전체 보기.
텃밭: 12개 밭 중 선택 → 여섯 작물 심기 → 물주기 문제 → 수확.
가방: 작물과 동물 생산물 판매. 주요 미션도 작물을 성장시킵니다.
동물: 닭·토끼·양·오리에게 먹이/물/빗질/청소. 네 번 돌보면 생산물.
꾸미기: 장식 선택 → 지도에서 미리보기 → 설치. 길과 출입구 보호.
우리 집: 네 단계 외관, 재료와 별씨앗으로 증축 문제, 실내 걷기.
상단 날씨: 자동 날씨와 시간 관찰. 하루 10분, 대화창에서는 시간 정지.
비는 밭을 적시고 작물을 키우며 동물은 밤과 비에 축사에서 쉽니다.
작은 사건은 게임 날짜당 최대 한 번이며 작물·동물을 잃지 않습니다.
이야기: 진행에 따라 다섯 장이 열립니다. 이동 중 자동 이야기는 보류됩니다.
설정: 효과음, 움직임, 진행 초기화(두 단계 확인).

저장
localStorage의 decimal-farm-v1 키를 유지하여 이전 학습·재산을 옮깁니다.
동물·집·날씨·작물 종류·꾸미기 위치·이야기도 자동 저장합니다.
다른 기기와 동기화되지 않으며 사이트 데이터 삭제 시 기록이 사라집니다.

수정 안내 (전체 소스)
dist/js/learning-config.js: 승급 연속 정답 수·복습 주기 등 자동 출제 설정.
dist/js/adaptive.js: 정수 연산 기반 숫자 생성·관계 문제·난도 저장.
dist/js/question-data.js: 40문제의 a,b,op,answer,story,hint,explanation.
각 구역 첫 5개는 주요, 뒤 3개는 반복. 문제 수와 id는 유지하세요.
dist/js/questions.js: 공간·주민·대사·건물 좌표.
dist/js/world.js: 36×36 지도·길·연못·충돌·밭·장식 가격·배치 규칙.
dist/js/core.js: 정확한 소수 채점·주요 미션·기본 저장.
dist/js/life.js: 생활 문제·작물/동물 목록·집 비용·시간/날씨·상태 이전.
dist/js/features.js: 생활 메뉴·집 내부 조작·꾸미기 미리보기·이야기.
dist/js/scene.js: 카메라·지형·애니메이션·날씨·실내 렌더링.
dist/js/render.js: 기본 자산 로딩 및 원래 렌더러.
dist/js/app.js: 이동·주민 문제 UI·설정·프레임 루프.
dist/storybook.css, dist/style.css: 화면·태블릿 대응.
dist/assets/story/: 새로 만든 독창적인 투명 PNG 75종.

자산 교체
scene.js의 자산 목록과 assetURL, render.js의 assetManifest를 수정합니다.
PNG/WebP를 사용하며 새 story 자산 바닥 기준점은 (가로/2, 세로−8)입니다.
GLB 직접 로딩은 아직 지원하지 않습니다. WebGL 렌더러가 필요합니다.
자산 재생성: Python+Pillow에서 tools/make_story_assets.py 실행.
게임 실행에는 Python/Pillow가 필요하지 않습니다.

현재 구현 범위와 제한
Canvas 2D의 아이소메트릭 픽셀 게임입니다. 실제 3D 지형은 아닙니다.
우리 집 내부를 걸을 수 있고, 학습 건물은 주민 미션 화면으로 연결됩니다.
동물 이동은 정해진 서식 범위의 반복 움직임이며 비/밤에는 쉼터로 전환합니다.
세로셈은 자리 정렬과 힌트를 제공하며 세밀한 받아내림 단계 애니메이션은 없습니다.
설치한 장식의 이동/회수, 가구 자유 배치, 멀티플레이는 포함하지 않았습니다.

교사 계정으로 로그인한 뒤 새 수업을 만들고, 생성된 학생 참여 링크를 배부합니다.
일반 GitHub 게임 주소는 자유 연습용이며 학생 이름을 수집하지 않습니다.
수업 참여 링크에서는 이름·학교·학년·반·번호를 입력해야 활동을 시작합니다.
활동 중 답 제출 후와 30초 간격으로 기록이 전송되고, 활동 마치기에서 최종 제출합니다.
서버 확인이 끝난 뒤 제출 완료 화면을 보여 줍니다. 연결 실패 시 재시도할 수 있습니다.
탭 닫기·기기 강제 종료 자체는 웹에서 막을 수 없습니다. 탭 종료 경고와 마지막 저장을 시도합니다.
교사는 첫 시도 정답률·전체 시도 정답률·활동 시간·완료 문제·힌트·문제별 기록을 확인하고 XLSX로 저장할 수 있습니다.
활동 시간은 화면이 보이고 최근 2분 이내 조작한 시간을 셉니다. 문제 읽기와 생각하는 시간도 포함합니다.
학생 참여 정보와 전송 토큰은 해당 탭의 sessionStorage에 저장하고, 최종 제출 후 지웁니다.
기록은 교사 전용 서버의 DB에 저장되며 학생용 공개 GitHub 소스에는 들어가지 않습니다.
